# 方块清单

共 23 个方块，全部在 `registry/ModBlocks.kt` 注册，`registry/ModItems.kt` 自动补 BlockItem。
所有方块共用同一套属性：`strength(-1.0f, 100.0f)`（不可破坏）+
`requiresCorrectToolForDrops()`；石材类 `MapColor.STONE` / `SoundType.STONE`，
tg_blue 用 `MapColor.COLOR_LIGHT_BLUE` / `SoundType.GLASS`。

## 楼梯与台阶

下列 5 个基块各派生出 `_stairs` 与 `_slab`：

`bricks_brown_white`、`bricks_brown_black`、`bricks_grey_black`、
`bricks_white_black`、`ow_02_cube`

共 10 个衍生方块，合计 23 个（13 + 10）。

* 楼梯是 `HorizontalStairsBlock`（`StairBlock` 的空子类），以基块默认状态作为
  楼梯的基础状态，blockstate 为 40 个变体，与 1.21.11 版本逐字段一致；
* 台阶是原版 `SlabBlock`，`type=bottom/double/top` 三变体，
  `double` 使用基块模型。

## 碰撞箱

| 方块 | 形状 |
| --- | --- |
| `lamp_post` | `Shapes.box(6, 0, 6, 10, 16, 10)` |
| `ow_02` | `Shapes.box(0, 0, 3, 16, 16, 13)`，朝向为东/西时交换 X/Z |
| `a2_openwork` | 整块包围盒 |
| `support_bar` | `Shapes.box(7.5, 0, 0, 8.5, 16, 16)`，朝向为东/西时交换 X/Z |
| `a2_wall_lamp` | 整块包围盒，但碰撞箱与相机碰撞箱为空（`getCollisionShape` / `getVisualShape` 返回空） |

`HorizontalWallBlock` 的 `facing` 默认朝北，放置时取玩家水平朝向，
`rotate`/`mirror` 只改 `facing`。

## 标签

`data/minecraft/tags/block/walls.json` 由 `ModBlockTagsProvider` 生成，
只包含 `minelzu:ow_01`、`minelzu:ow_02`（与 1.21.11 版本一致）。
